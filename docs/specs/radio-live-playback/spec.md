# 라디오 라이브 채널 검색과 재생

용어는 [GLOSSARY.md](../../../GLOSSARY.md)를 따릅니다. 루트 `PRODUCT.md`는 아직 없어서 앱 전체 전제는 사용자가 이 작업을 요청하며 한 말(방송국 검색, 채널 선택, 재생, 취침 타이머)만 반영합니다. UI 구성은 [ui-composition](../../decisions/ui-composition.md) 결정을 따릅니다.

이 문서는 이전 판(SBS 두 채널만 다루고 채널 선택 뒤 재생 메뉴에서 재생을 누르던 흐름)을 대체합니다. 사용자의 최신 요청이 "방송국을 고르면 채널 아이콘과 이름이 나오고, 채널을 누르면 재생하고 정지할 수 있게"로 바뀌었기 때문입니다.

## 사용자에게 보이는 결과

- 사용자가 방송국 이름이나 채널 이름을 검색하면 일치하는 방송국이 나옵니다.
- 방송국을 선택하면 그 방송국의 채널이 아이콘과 이름으로 나옵니다.
- 채널을 누르면 바로 라이브 방송이 재생되고, 정지할 수 있습니다.
- 재생 중에는 10분, 30분, 60분 중 하나를 골라 취침 타이머를 걸 수 있고, 시간이 지나면 재생이 자동으로 멈춥니다.
- 재생 상태 표시줄의 채널 이름과 정지 버튼 사이 빈 공간에서 고양이 캐릭터가 재생 중에는 춤추며 돌아다니고, 정지하면 의자에 앉아 쉽니다.
- 화면 맨 위 오른쪽의 아이콘 버튼으로 화면을 모바일폰 크기(너비 390px)로 미리 볼 수 있고, 한 번 더 누르면 원래 데스크탑 크기로 돌아옵니다.

### 기능

- 방송국 검색, 방송국 선택, 채널 아이콘·이름 표시, 채널 재생과 정지, 취침 타이머를 포함합니다.

## 수용 기준

1. 검색어가 비어 있으면 모든 방송국이 나옵니다.
2. 검색은 방송국 이름 또는 그 방송국 채널 이름의 대소문자 무시 부분 일치입니다. `sbs`는 SBS를, `러브`는 SBS를, `fm`은 FM 채널이 있는 방송국들을 보여 줍니다. 일치하는 방송국이 없으면 결과 없음 상태가 나옵니다.
3. 방송국을 선택하면 그 방송국의 채널이 아이콘과 이름으로 나옵니다. `sbs`를 검색해 SBS를 선택하면 SBS 러브FM과 SBS 파워FM에 해당하는 채널 두 개가 나옵니다.
4. 채널을 누르면 연결 중 상태를 거쳐 그 채널의 라이브 방송이 재생되고, 그 채널이 재생 중임이 표시됩니다. 실제 앱에서 재생 위치가 계속 증가하고 오디오가 끊기지 않아야 합니다.
5. 범위 표의 36개 채널 각각에 대해 4번이 성립합니다.
6. 재생 중인 채널을 다시 누르거나 정지 버튼을 누르면 소리가 멈춥니다. 이때 채널 이름은 표시줄에 "정지됨" 상태로 그대로 남고, 정지 버튼이 재생 버튼으로 바뀝니다. 재생 버튼을 누르거나 정지된 채널을 다시 누르면 멈춘 지점이 아니라 그 시점의 라이브 방송이 나옵니다.
7. 재생 중에 다른 채널을 누르면 이전 채널이 멈추고 새 채널이 재생됩니다. 두 채널의 소리가 겹치지 않고, 재생 중 채널은 항상 하나입니다.
8. 재생 중에 다른 방송국을 선택하거나 검색어를 바꿔도 재생은 이어지고, 어떤 채널이 재생 중인지 보이고 정지할 수 있습니다.
9. 재생 중일 때 취침 타이머 선택지 10분, 30분, 60분과 해제 조작이 나옵니다. 재생 중이 아닐 때는 타이머를 걸 수 없습니다.
10. 타이머를 걸면 남은 시간이 표시되고, 정해진 시간이 지나면 재생이 자동으로 멈추고 취침 타이머로 종료되었음이 표시됩니다. 브라우저 탭이 뒤에 있어도 정해진 시각 근처(수 초 이내)에 멈춥니다.
11. 타이머가 걸린 상태에서 채널을 바꾸면 타이머는 그대로 이어집니다. 사용자가 직접 정지하거나 타이머를 해제하면 타이머가 사라지고 자동 종료가 일어나지 않습니다. 다른 시간을 고르면 이전 타이머를 대체합니다.
12. 주소를 받지 못하거나 재생이 실패하면 그 채널에 오류 상태와 다시 시도 동작이 나옵니다. 한 채널의 실패가 다른 채널과 검색 화면을 막지 않습니다.
13. 좁은 화면에서도 검색, 방송국 선택, 채널 목록, 재생 중 표시와 정지, 타이머가 정보의 순서대로 쌓이고 동작이 숨겨지지 않습니다.
14. 재생 상태 표시줄은 재생하지 않을 때도 남습니다. 채널을 고르지 않은 처음 상태와 재생에 실패한 상태에서는 "재생 중인 채널이 없습니다"만 보여주고 캐릭터와 버튼은 없습니다. 정지한 뒤에는 정지한 채널 이름, 앉아서 쉬는 캐릭터, 재생 버튼이 남습니다.
15. 연결 중이거나 재생 중이면 사용자가 제공한 캐릭터 이미지(`public/character/dancer.png`)가 채널 이름과 버튼 사이 공간을 좌우로 왔다 갔다 하며, 같은 그림을 튕기고 기울이고 찌그러뜨리는 여러 장면을 번갈아 보여주며 춤춥니다. 사용자가 정지해 채널이 "정지됨"으로 남은 동안에는 사용자가 제공한 앉은 모습의 이미지(`public/character/resting.jpg`)가 가운데에서 가만히 숨 쉬듯 쉽니다. 재생 중인 채널이 없는 처음 상태와 재생 실패 상태에서는 캐릭터를 보여주지 않습니다. 각 이미지 파일이 없거나 불러오지 못하면 춤추는 고양이, 의자에 앉아 쉬는 고양이가 대신 나옵니다.
16. 고양이는 장식이라 재생, 정지, 타이머 동작을 막지 않습니다. 사용자의 요청에 따라 운영체제의 "움직임 줄이기" 설정과 관계없이 항상 움직입니다. 스크린 리더에는 현재 모습(춤추는 고양이, 의자에서 쉬는 고양이)이 이미지 설명으로 전달됩니다.
17. 화면 맨 위 오른쪽에 화면 크기 전환 아이콘 버튼이 있습니다. 데스크탑 크기일 때는 "모바일 화면으로 보기", 모바일 크기일 때는 "데스크탑 화면으로 보기"라는 이름과 그에 맞는 아이콘을 가집니다.
18. 모바일 크기로 바꾸면 화면 내용이 너비 390px의 폰 모양 틀 안에 가운데 정렬로 들어가고, 채널 목록 등 반응형 배치가 실제 모바일 레이아웃(한 줄에 하나)으로 바뀝니다. 브라우저 창이 390px보다 좁으면 창 너비를 넘지 않습니다.
19. 크기를 전환해도 재생 중인 채널, 정지 상태, 취침 타이머, 검색어, 선택한 방송국은 그대로 유지되고 재생이 끊기지 않습니다. 한 번 더 누르면 처음 데스크탑 레이아웃으로 돌아옵니다.

## 확정한 제약과 근거

- 사용자가 직접 정한 것: 방송국을 고르면 채널 아이콘과 이름이 나옴, 채널을 누르면 재생, 정지 가능, 취침 타이머 선택지가 10분·30분·60분이고 시간이 지나면 자동 종료됨, SBS 외 방송국과 검색으로 찾을 수 있는 국내 방송국을 확인해 추가함.
- 채널 포함 기준은 "익명으로 접근했을 때 실제 브라우저에서 재생 위치가 흐르는 것"입니다. 사용자가 방송국을 찾아 추가하도록 위임했고, 이 기준으로 36개를 포함했습니다.
- 재생 확인은 실제 실행 중인 앱에서 합니다. 코드나 테스트 통과만으로 재생이 된다고 보지 않습니다.
- 스트림 주소는 재생을 누를 때마다 새로 받습니다. 일부 방송국의 주소는 서명이나 토큰이 붙어 시간이 지나면 만료됩니다.

## 가정 (사용자가 바꿀 수 있음)

- 채널 아이콘은 방송국 로고가 아니라 공통의 라디오 아이콘으로 합니다. 방송사 로고의 사용 허락 여부를 확인하지 못했기 때문입니다.
- 재생 중 채널은 한 번에 하나뿐이고, 같은 채널을 다시 누르면 정지입니다. 취침 타이머로 멈췄을 때도 채널은 정지됨 상태로 남아 재생 버튼으로 다시 들을 수 있습니다.
- 방송국을 검색하는 화면에서 검색어를 비우면 전체 방송국이 나옵니다.
- 취침 타이머는 재생 중에만 걸 수 있고, 새로고침하면 사라집니다. 타이머는 채널을 바꿔도 이어집니다.
- 한 채널의 이름은 방송국 안에서 보이는 짧은 이름(예: `1라디오`)이고, 방송국을 거치지 않고 보여야 할 때는 방송국 이름을 앞에 붙입니다(예: `KBS 1라디오`).
- 타이머의 시간 경과 확인은 시계를 앞당기는 방식으로 해도 됩니다.

## 범위 밖

- 고양이의 종류나 모양을 사용자가 고르는 기능, 소리에 맞춰 움직이는 효과.
- 특정 기기(아이폰, 갤럭시 등) 크기 선택, 가로 방향, 기기 틀의 노치나 베젤 표현. 모바일 크기는 390px 한 가지입니다.
- 아래 후보는 제외했습니다.
  - CPBC 가톨릭평화방송: 공식 재생 주소에 로그인·유료 표시가 있고, 로그인 없이 되는 고정 주소는 http만 지원해 https 페이지에서는 브라우저가 막습니다.
  - 경기방송: 폐국으로 알려져 있으나 웹에서 확인하지 못했습니다.
  - 지역별 BBS·CPBC·CBS·극동방송·TBN·WBS 나머지, iFM 보이는 라디오, 글로벌광주방송: 이번에 확인하지 못했습니다.
- 방송사 로고, 프로그램 정보 표시, 로그인, 즐겨찾기, 재생 기록, 다시듣기와 다운로드.
- 광고를 제거하거나 가공하는 동작. 광고는 현재 대안의 불편으로만 알고 있고 이 서비스가 약속하는 변화로 정해지지 않았습니다.

## 미룬 결정

- 방송사 로고 사용 여부(권리 확인 뒤).
- 화면을 벗어나거나 기기가 잠겨도 재생을 이어 갈지.
- 방송국·채널 목록을 어디서 관리하고 어떻게 늘릴지.
- 앱이 https로 배포될 때 http 전용 스트림(CPBC)을 지원할지.

## 남은 위험

- 캐릭터 이미지(춤추는 모습 `dancer.png`, 쉬는 모습 `resting.jpg`)는 닌텐도의 카비로 보이는 저작권 있는 그림이며, 사용자가 자신의 개인 페이지에서 쓰기로 정했습니다. 쉬는 모습은 SoundCloud 곡 "망했지만그만할래 (prod.moonlikethis)"의 대표 이미지(1080×1080 JPEG)입니다. 사용자의 결정에 따라 두 파일은 `public/character/`에 두고 저장소에 커밋합니다. 저장소를 공개하거나 배포하면 저작권 문제가 생길 수 있습니다. 파일이 없거나 불러오지 못하면 고양이가 대신 나옵니다.
- 원본 이미지가 한 장뿐이라 동작이 서로 다른 그림은 없고, 같은 그림에 이동·회전·찌그러짐을 주는 변형으로 춤을 표현합니다. 투명 배경이 없는 이미지라 흰색 배경이 있는 화면에서만 자연스럽습니다.
- 고양이 애니메이션이 "움직임 줄이기" 설정을 따르지 않습니다. 움직임에 민감한 사용자는 표시줄 안의 작은 장식 움직임을 피할 수 없습니다.
- 대부분의 주소는 방송사가 공개 문서로 제공한 API가 아니라 방송사 웹 재생 화면이 쓰는 주소이거나 커뮤니티가 모은 주소입니다. 응답 형식, 토큰 방식, 접근 조건이 예고 없이 바뀌면 해당 채널이 멈출 수 있고, 서비스 이용 조건에 어긋나는지는 확인하지 못했습니다. 특히 EBS FM은 방송사 페이지 HTML에서 주소를 읽는 방식이라 가장 깨지기 쉽습니다.
- SBS와 CPBC 응답에 해외 제한 표시가 있고, 다른 방송국은 해외에서 시험하지 못했습니다. 확인은 한국 네트워크에서만 했습니다.
- SBS 응답에는 저작권 문구가 있었지만 재생은 되었습니다. 프로그램이나 시간대에 따라 막히는지는 확인하지 못했습니다.
- MBC 토큰의 만료 시간과, 12시간 이상 재생을 이어 갈 때의 동작은 확인하지 못했습니다.
- 방송국·채널 이름 일부는 정식 표기를 확인하지 못한 임시 이름입니다.
- 일부 채널은 오디오 전용이 아닙니다(TBS, 아리랑라디오, EBS FM). 모바일 데이터 사용량이 늘 수 있습니다.
- 36개 채널을 한 번에 확인한 시점은 한 번뿐이어서, 시간이 지나면 일부가 막힐 수 있습니다.
